# 生命结构实验室

面向高中生物课程的交互式 3D 可视化实验室。项目以单页网页呈现细胞、遗传、生态与人体生理四大模块，支持结构观察、分层拆解、过程动画和课堂演示。

[查看或下载完整 HTML](./生命结构实验室.html)

## 项目概览

生命结构实验室将高中生物中的微观结构、动态过程和系统关系转化为可旋转、可缩放、可选择的三维教学模型。它适合课堂投屏讲解、学生自主观察、复习结构层级，以及对抽象生命过程进行分步演示。

页面中的模型均带有结构树、功能说明、教材知识点、易错提示、观察建议和模型局限说明；P0 表示核心模型，P1 表示扩展模型。

## 核心规模

- 4 个课程模块
- 44 个完整教学模型，其中 P0 核心模型 27 个、P1 扩展模型 17 个
- 346 个可识别结构部件
- 176 个过程动画步骤

## 主要功能

- Three.js 实时 3D 观察：旋转、缩放、平移、结构拾取与平滑聚焦
- 模型搜索、课程模块切换，以及 P0/P1 优先级筛选
- 结构层级树与中英文名称、功能、知识点联动
- 单独观察、高亮、半透明、外层透明和父子结构专注模式
- 分层拆解滑块与剖切观察
- 动画时间轴、逐步播放、速度调节和课堂演示模式
- 顶部、正面、侧面、背面、底部等预设视角与完整模型适配
- 标签开关、截图、全屏、渲染性能档位和一键复原
- 响应式布局、移动端导航、键盘操作、文字等价信息和减少动态效果

## 快速开始

### 直接打开

下载或克隆项目后，用现代浏览器打开 `生命结构实验室.html`。页面的 Three.js 依赖来自公共 CDN，因此首次加载需要网络连接。

### 使用本地静态服务器（推荐）

先在资源管理器中打开项目文件夹，再在该文件夹的终端中运行：

```powershell
python -m http.server 8000
```

如果系统使用 Python Launcher，也可以运行：

```powershell
py -m http.server 8000
```

然后访问：

```text
http://localhost:8000/生命结构实验室.html
```

### 从源片段重建 `index.html`

项目保留了模型数据、界面和三维引擎的拆分源文件。安装 Node.js 后可执行：

```powershell
node .\tests\build-index.mjs
node .\tests\validate-index.mjs
```

第一条命令将源片段合成为仓库根目录的 `index.html`，第二条命令执行结构完整性与实现约束检查。

## 操作说明

### 鼠标与触控

- 左键拖拽：旋转模型
- 滚轮或双指手势：缩放模型
- 右键拖拽，或按住 `Shift` 后左键拖拽：平移视角
- 单击结构：查看名称、功能和知识点
- 双击结构：聚焦观察

### 键盘快捷键

- `R`：重置视角
- `F`：聚焦选中结构
- `Space`：播放或暂停过程动画
- `Esc`：取消选择、关闭浮层或收起移动端导航

### 页面控件

- “拆解”滑块用于观察结构之间的空间层级
- “外层半透明”“剖切观察”和“专注模式”用于查看内部结构
- “自由观察”适合自主探索；“课堂演示”会同步动画阶段、镜头与讲解
- 时间轴支持跳转到任意关键阶段，并可调整播放速度
- 视角导航可快速切换六个方向，或将完整模型适配到当前视口

## 验证与兼容性

项目数据和成品页已完成以下开发验收：

- 静态脚本检查：四个模块共 44 个模型且模型 ID 唯一，P0/P1 数量为 27/17，346 个结构部件和 176 个动画步骤均有实际内容
- 浏览器人工检查：逐个切换 44 个模型，确认均可载入三维视口并操作核心控件
- 浏览器人工检查：在 1920×1080、1366×768、1024×768 和 390×844 四种视口尺寸下检查页面布局
- 浏览器人工检查：模型卡片保持双列网格与区域内部滚动，没有通过缩小字号处理内容溢出

运行环境需要支持 JavaScript 模块、Import Maps 和 WebGL。建议使用近期版本的 Chrome、Edge、Firefox 或 Safari，并开启浏览器硬件加速。

## 教学适用范围

本项目用于高中生物教学演示与概念理解。模型的形态、颜色、数量、距离和运动经过教学化简化，不代表真实比例或真实颜色；具体知识范围请以任课教师、当地课程标准和教材为准。

人体相关内容仅作生物学教学示意，不用于医学诊断、治疗决策或科研测量。

## 技术与网络依赖

- HTML、CSS、原生 JavaScript
- Three.js `0.186.1`
- OrbitControls
- WebGL

Three.js 和 OrbitControls 默认通过 jsDelivr 加载。离线部署时，需要下载对应版本文件并修改页面中的 Import Map；否则三维视图无法在断网环境中初始化。

## 部署到 GitHub Pages

1. 运行 `node .\tests\build-index.mjs` 生成根目录入口 `index.html`。
2. 将 `index.html` 及项目所需文件提交到 GitHub 仓库。
3. 在仓库的 GitHub Pages 设置中选择包含 `index.html` 的分支和根目录作为发布来源。
4. 部署完成后，通过 GitHub 提供的 Pages 地址访问项目。

发布前建议再次运行 `node .\tests\validate-index.mjs`。项目没有声明开源许可证时，默认保留全部权利；如需允许他人复制、修改或再发布，请由仓库所有者另行添加合适的许可证文件。
